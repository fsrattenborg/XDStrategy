# XDStrategy
Generate successive xd.mas files for refinement strategies.

## Setup
- Set location of XDConstraints (if to be used).
- Run script in folder with input files

## Input files
- XD masterfile.
- Instructions file (or written by the script).
- Constraint files (written as INCLUDE commands) (optional).

### Initial masterfile setup
- Configure LCS and symmetry restrictions on multipoles (incl. pseudosymmetries).
- Set values (TP/KAP/LMX/etc.) in ATOM table.
